## What it does

Lets assistants like Cursor or Claude control Unreal Engine, useful for previs and LED volume content.

## How to set it up

1. Install the Unreal plugin and the Python MCP server per the README.
2. Connect Cursor, Windsurf or Claude Desktop.
3. Use it for previs and content builds, not for an LED volume during a shoot.

Source project: [chongdashu/unreal-mcp](https://github.com/chongdashu/unreal-mcp)

## FAQ

### Production ready?
No. The README marks it experimental and warns of breaking changes.

### Why for live events?
For fast previs of stages and LED content in Unreal.
