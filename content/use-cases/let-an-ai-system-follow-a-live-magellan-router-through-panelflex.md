## What it does

Imagine's Magellan PanelFlex-AI, introduced at IBC2026, organizes Magellan Control System status into an MCP interface so an AI system can follow and act on live routing information.

## How to set it up

1. PanelFlex is the control-surface layer for a Magellan Control System. Imagine describes that system as IP/SDI routing control, real-time monitoring and an operator work surface.
2. Design each operating position in Magellan PanelFlex-Canvas. The real-time engine sends those canvases to HTML5 web panels, multiviewer surfaces and physical panels. Signal names can be set freely at every position, for every user.
3. Magellan PanelFlex-AI is the MCP piece. Imagine says it organizes key system information so AI systems can follow and act on live status. The company demonstrated the portfolio at IBC2026 (11–14 September 2026, RAI Amsterdam, stand 1.B73). The 1 September 2026 announcement does not publish a standalone server, port or client config.

Source: [Imagine Communications, 1 September 2026](https://imaginecommunications.com/insights-and-resources/imagine-unveils-latest-control-portfolio-advances-at-ibc2026-with-debut-of-magellan-panelflex/)

## FAQ

### What can the AI actually do?
The release says AI systems can quickly follow and act upon status and information from the live system. It does not name individual tools, commands or a downloadable MCP package.

### Is the MCP only on PanelFlex?
Imagine says it is introducing these MCP interfaces across its control portfolio. PanelFlex-AI is the one called out for the Magellan system.
