## What it does

Unofficial Companion module with clip slots and feedback, so button surfaces and automations can drive Resolume.

## How to set it up

1. Download the .tgz from the releases and use Companion's Install from file, or unzip into %APPDATA%\companion\modules on Windows.
2. In Arena open Preferences → OSC and enable input and feedback.
3. In Companion add the connection with the Arena IP, port 7000, and feedback port 7001.

Source project: [ElytaM/companion-module-resolume-arena-osc-unofficial](https://github.com/ElytaM/companion-module-resolume-arena-osc-unofficial)
