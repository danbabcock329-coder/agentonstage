## What it does

Community grandMA2 plugins including AI-assisted tools such as cue info editors.

## How to set it up

1. Read the Getting Started section for prerequisites and installation into grandMA2.
2. Load a plugin on onPC first and run it against a test show.
3. Use the plugin-development notes if you want an AI to generate new plugins in MA2 command syntax.

Source project: [chienchuanw/gma2-plugins](https://github.com/chienchuanw/gma2-plugins)

## FAQ

### Why does this exist?
MA's plugin docs don't publish the Lua API, so the repo collects community knowledge and AI-assisted plugins.

### Which console?
grandMA2, not MA3.
