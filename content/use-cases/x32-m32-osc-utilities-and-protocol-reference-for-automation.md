## What it does

Patrick Maillot's long-running collection of X32 tools and protocol notes, the foundation many agent integrations build on.

## How to set it up

1. Browse the repo for the utility you need; X32_Command is a command-line tool for sending and reading X32 OSC.
2. Build with the C toolchain the README describes (MinGW/Eclipse on Windows) or use the author's precompiled releases.
3. Use the tools and the OSC notes as a reference when you script or wrap the console for an agent.

Source project: [pmaillot/X32-Behringer](https://github.com/pmaillot/X32-Behringer)

## FAQ

### Who maintains it?
Patrick-Gilles Maillot, who has published X32 utilities since 2014.

### Is it an AI tool?
No. It's the protocol groundwork that agent integrations rely on.
