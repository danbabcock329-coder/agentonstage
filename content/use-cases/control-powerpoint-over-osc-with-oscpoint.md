## What it does

A PowerPoint add-in that lets show control or agents advance and query slides via OSC.

## How to set it up

1. Download the add-in from oscpoint.com and install it in PowerPoint on Windows.
2. Add the OSCPoint Companion module, or use any OSC client.
3. Map next/previous, go-to-slide and media actions to buttons or show-control cues.

Source project: [phuvf/oscpoint](https://github.com/phuvf/oscpoint)

## FAQ

### Mac support?
No, it's Windows PowerPoint only.

### Feedback?
Yes. Current slide and other states are sent back for button feedback.
