## What it does

TiMax built an MCP server into its TiMax2 SoundHub software so an AI assistant can do the slow first pass on a spatial audio show file. The designer describes the show, and the assistant imports speaker layouts from Martin Audio DISPLAY 3, d&b ArrayCalc or EASE files, then creates and edits speakers and their positions, image definitions, subspaces, scaling surfaces and output labels. It can also fix venue orientation when a prediction file doesn't match how you want it laid out in TiMax.

TiMax says this cuts initial data entry from a typical four or five hours to around thirty minutes. The scope is deliberately narrow: setup only. It stays out of the live cue path and the running of the show, and everything it makes is an ordinary TiMax object you can see, edit and undo.

## How to set it up

1. Download the latest TiMax2 SoundHub release for Mac or PC. TiMax MCP is included and needs no extra licence.
2. Check the supported AI assistants on the TiMax MCP page and connect your own account (free or paid). Claude Desktop is one TiMax names.
3. With SoundHub running, describe the show and point the assistant at your DISPLAY 3, ArrayCalc or EASE prediction file.
4. Review every speaker, image definition and subspace it creates before you build the creative design on top.

## FAQ

### Does it need TiMax hardware?
No. The setup and design workflow runs without hardware attached, so you can try it the same day you download it.

### Can it run cues during the show?
No. TiMax says its scope ends at initial setup and sits outside the live cue path.

### Does it cost extra?
No. It's free in the standard SoundHub release, but you bring your own AI assistant account.
