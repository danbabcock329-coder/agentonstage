## What it does

A browser app that turns an X32 or M32 .scn file into a printable channel plot for a show binder or rider, with no console connected.

## How to set it up

1. Open the hosted web app at lucaelin.github.io/scnplot.
2. Load an X32/M32 .scn file.
3. Print the channel overview for FOH or add it to the band's tech rider.

Source project: [lucaelin/scnplot](https://github.com/lucaelin/scnplot)

## FAQ

### Do I need a console?
No. It reads the scene file on your computer.

### Who is it for?
Audio engineers, musicians and tour managers.
