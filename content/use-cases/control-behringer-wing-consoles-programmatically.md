## What it does

A C API for Behringer WING consoles. The GitHub repo now points to the author's own download site for the library.

## How to set it up

1. Read the GitHub README; the library itself is no longer hosted there.
2. Download wapi and its demo programs from the author's site (x32ram.com/wapi) and the API docs from the linked Drive file.
3. Link the C library into your own tool or agent wrapper to read and set WING parameters.

Source project: [pmaillot/wapi](https://github.com/pmaillot/wapi)

## FAQ

### Why isn't the code on GitHub?
The author moved it off GitHub over a GPL licensing concern.

### Are there ready-made tools?
Yes, the author lists precompiled WING utilities on his Google Sites page.
