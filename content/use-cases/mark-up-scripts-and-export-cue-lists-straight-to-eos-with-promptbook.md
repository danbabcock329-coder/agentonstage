## What it does

Promptbook is a digital prompt book for stage managers. It handles script markup, automatic standbys, live Eos and QLab cue tracking, and CSV export for import into ETC Eos.

## How to set it up

1. Import the script PDF or Word document and create colour-coded cue lists.
2. Drag across a line to place a cue; standbys are generated automatically from GO cues.
3. Export a PDF prompt book, a cue sheet spreadsheet or an Eos CSV.
4. In show mode, connect to auto-discovered Eos and QLab machines to track cues live.

Source: [Appleby Technical vendor page](https://applebytechnical.com/promptbook)

## FAQ

### What happens when the script changes?
Upload the revised script and it moves cues across, suggesting matches or asking you to review where lines changed.

### Cost?
Core features are free, and Pro adds QLab/Eos tracking and more.
