## What it does

Embody packages a broad set of MCP tools for TouchDesigner, giving an agent structured access to operators, parameters and project files.

## How to set it up

1. Download the Embody .tox from the repo's /release folder and drag it into your project.
2. Walk through the Setup Wizard: choose how much autonomy the AI (Envoy) gets, which assistant to connect, permissions and what to externalize to disk.
3. Nothing is applied until the wizard's final click, so you can re-run it any time from the Setup Wizard pulse.
4. Use Check for Update (or Auto-Update) on the About page to stay current; settings survive updates.

Source project: [dylanroscover/Embody](https://github.com/dylanroscover/Embody)

## FAQ

### Does Embody change my project immediately?
No. The wizard collects choices first and only applies them on the last step.

### Where is the full documentation?
At dylanroscover.github.io/Embody, linked from the README.
