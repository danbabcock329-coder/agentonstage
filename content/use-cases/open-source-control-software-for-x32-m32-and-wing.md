## What it does

An open project running custom control software on digital consoles, useful for experimenting with automation.

## How to set it up

1. Start from the OpenX32 or OpenWING project pages, which explain the custom Linux firmware these consoles run.
2. Build OpenMixerControl using the provided Docker workflows (XM32, WING or PC/SDL2 targets).
3. Try it on the PC/SDL2 build before going anywhere near a real console.

Source project: [OpenMixerProject/OpenMixerControl](https://github.com/OpenMixerProject/OpenMixerControl)

## FAQ

### Does this replace the console firmware?
OpenX32 and OpenWING are custom Linux firmware; treat them as experimental and never on a show desk.

### Where's the community?
On the OpenMixerProject Discourse, linked from the README.
