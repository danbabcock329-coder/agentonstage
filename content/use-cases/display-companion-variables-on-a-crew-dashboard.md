## What it does

A dashboard for showing Companion variables, like timers and states, to crew screens.

## How to set it up

1. Download the desktop app (Mac, Linux, Windows) or run the install script on a Raspberry Pi or NUC.
2. Connect to your Companion instance and choose the variables to display.
3. Put it on a backstage or FOH screen for timers and states.

Source project: [tomhillmeyer/companion-dashboard](https://github.com/tomhillmeyer/companion-dashboard)

## FAQ

### Pi 5?
Not supported yet according to the README.

### Remote config?
The Linux server build starts a web server for remote configuration.
